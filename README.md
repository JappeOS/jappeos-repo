## Overview

This is the `pacman` repository for JappeOS that contains the database and builds of JappeOS system programs and apps. It is currently hosted on GitHub pages.

## Role in the OS

Used for system components (desktop, greeter, apps, etc.) to manage and update them properly through the package manager.
